# BKR Politician Website

Modern website for **B Kishore Reddy** - Congress MLA Candidate, Quthbullapur Constituency.

Dynamic website with Flask Backend + SQLite Database.

## 🚀 Quick Start

**Windows:**
```bash
START.bat
```

**Mac/Linux:**
```bash
chmod +x deploy.sh && ./start-servers.sh
```

Visit: http://localhost:8080

## 🌍 Deploy to Hostinger

```bash
# Windows
deploy.bat

# Mac/Linux
./deploy.sh
```

See [DEPLOYMENT_GUIDE.md](DEPLOYMENT_GUIDE.md) for full instructions.
